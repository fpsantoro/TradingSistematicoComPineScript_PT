# TradingSistematicoComPineScript_PT
Estrategias em Pine Script - Trading Sistemático com Pine Script

Bem-vindo ao recurso oficial do livro! Aqui você encontrará todos os códigos em Pine Script prontos para copiar e colar no TradingView, sem precisar digitá-los manualmente.

## 📂 Lista das Estratégias
* [Anexo B : Código da estratégia Vortex] - Abra o arquivo `Vortex.txt`
* [Anexo D : Código da estratégia Pullback (com filtro baseado no RSI)] - Abra o arquivo `Pullback.txt`
* [Anexo E : Código da estratégia Trendline] - Abra o arquivo `Trendline.txt`
* [Anexo F : Código da estratégia Divergence] - Abra o arquivo `Divergence.txt`
* [Anexo G : Código da estratégia Breakout (com gestão de risco)] - Abra o arquivo `Breakout.txt`
* [Capítulo 12 : Código da estratégia Vortex (com gestão de risco)] - Abra o arquivo `Vortex_ATR.txt`
* [Capítulo 12 : Código da estratégia Pullback (com gestão de risco)] - Abra o arquivo `Pullback_ATR.txt`
* [Capítulo 12 : Código da estratégia Trendline (com gestão de risco)] - Abra o arquivo `Trendline_ATR.txt`
* [Capítulo 12 : Código da estratégia Divergence (com gestão de risco)] - Abra o arquivo `Divergence_ATR.txt`

## 🚀 Como usar esses códigos
1. Acesse a pasta acima e clique no arquivo de estratégia desejado.
2. No canto superior direito do código, clique no ícone **"Copiar conteúdo bruto"** (os dois quadrados sobrepostos).
3. Acesse o TradingView, abra o **Editor Pine**, cole o código e clique em **Adicionar ao gráfico**.
